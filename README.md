# Konfor Proje

İnşaat taahhüt şirketi için iç kullanım gelir–gider, backlog ve dashboard sistemi.

## Dokümantasyon

- Ürün ve teknik plan: [docs/URUN_PLANI.md](docs/URUN_PLANI.md)

## Hedef stack (özet)

- **İstemci:** Expo (React Native) + Expo Router — iOS, Android, Web (ortak kod)
- **API:** NestJS + Prisma + PostgreSQL
- **Auth:** Kullanıcı adı / şifre (admin oluşturur)
- **OCR:** Asenkron job (BullMQ) + Vision API
- **Monorepo:** pnpm workspaces + Turborepo

Kurulum ve uygulama kodu plan onayından sonra eklenecektir.
